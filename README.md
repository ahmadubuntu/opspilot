# OpsPilot

> An AI-first, plugin-based DevOps platform powered by MCP.

## Vision

OpsPilot is an extensible platform for DevOps and Platform Engineers that enables AI models to interact with infrastructure through secure plugins.

The project is designed around the Model Context Protocol (MCP) and follows a plugin-based architecture.

Open WebUI is used only as the user interface. All business logic lives inside the OpsPilot runtime.

## Goals

- AI-first architecture
- Plugin-based design
- Docker-first deployment
- Local-first execution
- Remote execution support
- Secure by default
