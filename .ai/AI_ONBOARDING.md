# AI Onboarding

If you are an AI assistant working on this repository:

Read the following files in order.

1. README.md

2. PROJECT_PRINCIPLES.md

3. .ai/PROJECT.md

4. .ai/STATUS.yaml

5. .ai/ROADMAP.yaml

6. .ai/DECISIONS.md

7. docs/adr/

Do not modify the architecture before understanding the existing decisions.

Do not introduce dependencies between plugins.

Do not place business logic inside Open WebUI.

Every code change should include:

- Tests
- Documentation
- AI documentation update
